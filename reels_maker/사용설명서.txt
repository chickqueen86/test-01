푸드 릴스 메이커 - 맥 사용 설명서

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[처음 한 번]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 압축을 푼 폴더에서 "푸드릴스메이커_실행.command" 를 마우스 오른쪽 클릭 → "열기" → 다시 "열기"
   (처음엔 더블클릭하면 "확인되지 않은 개발자" 경고로 막힙니다. 오른쪽 클릭 → 열기는 한 번만 하면 됩니다)
2. ffmpeg·Python 등이 없으면 자동으로 설치합니다. 맥 비밀번호를 물으면 입력하세요.
3. 대본 작성은 맥에 설치된 Claude Code(claude 명령)를 씁니다. 로그인만 되어 있으면 API 키는 필요 없습니다.
4. 대행사 로고(PNG)나 글자를 한 번 입력합니다 → 영상 왼쪽 위 + 마지막 엔딩 카드에 들어갑니다.
   아무것도 입력하지 않으면 로고·엔딩 카드 없이 만듭니다. 바꾸려면 메뉴 4번.
5. 처음 실행은 10~20분 걸릴 수 있습니다 (음성인식 모델 약 1.5GB 다운로드 포함).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[작업 순서] "푸드릴스메이커_실행.command" 더블클릭 → 번호 선택
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
① 1번 새 매장 폴더 만들기 → 매장 이름 입력
   → 작업/매장명_날짜/ 안에 1_촬영, 2_대본, 3_녹음, 4_완성 폴더가 생깁니다.

② 촬영 영상·사진을 1_촬영 폴더에 넣기 (개수 제한 없음)
   파일 이름 = 촬영 지침 컷번호_테이크 :  01_1.mov, 05_2_best.mov ...
   01 훅 클로즈업   02 들어올리기(젓가락·숟가락)   03 조리·곁들임   04 탑뷰·전체
   05 단면·칼질     06 진행자·인기                 07 외관         08 메뉴판
   가장 잘 나온 테이크는 이름 끝에 _best

③ 2번 대본 만들기 → 매장 선택 → 아는 정보(메뉴명, 가격 등) 입력
   → 2_대본/script.md 가 열립니다.
   - "확인 필요" 항목을 꼭 확인하세요 (가격·메뉴명 등 검색으로 확인 못 한 것)
   - 대본은 script.md 에서 직접 고쳐도 됩니다. 고친 글자가 그대로 자막이 됩니다.

④ 녹음해서 3_녹음 폴더에 넣기 (아이폰 음성메모 m4a 그대로 OK)
   - 한 줄씩 끊어서, 쉬지 말고, 최대한 빠르게 읽기 (목표 초당 7음절, 레퍼런스 속도)
   - 앞뒤 무음, 문장 사이 쉼, 속도는 프로그램이 자동으로 정리합니다 (최대 1.3배까지 빠르게)
   - 음악은 자동으로 만들어 넣습니다. 따로 쓰고 싶은 음악이 있으면 이름에 bgm 이 들어간 파일로 함께 넣기

⑤ 3번 영상 완성하기 → 매장 선택
   → 4_완성 폴더에 reel.mp4(완성본), reel_cover.jpg(표지), captions.srt(자막)

[자동으로 해 주는 것]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 컷 템포: 레퍼런스처럼 처음엔 빠르게(0.6초) → 점점 느리게
- 장면 선택: 대본 구간 내용에 맞는 장면, 그중 움직임·초점이 가장 좋은 순간만
- 초점 나간 구간 자동 제외 / 움직임 없는 장면은 천천히 확대
- 색감: 밝기·명암을 레퍼런스처럼 진하게, 음식 색은 원래대로
- 자막: 대본 글자 그대로, 목소리 타이밍에 맞춤
- 음악 자동 작곡(로파이, 저작권 걱정 없음) + 굽는 소리·써는 소리 효과음
- 표지: 가장 선명한 장면 + 대본의 표지 문구 3줄
