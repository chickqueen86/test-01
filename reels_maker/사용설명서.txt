식당 릴스 메이커 - 맥 사용 설명서

[처음 한 번]
1. 압축을 푼 폴더에서 "실행_맥.command" 를 마우스 오른쪽 클릭 → "열기" → 다시 "열기"
   (처음엔 더블클릭하면 "확인되지 않은 개발자" 경고로 막힙니다. 오른쪽 클릭 → 열기는 한 번만 하면 됩니다)
2. ffmpeg·Python 등이 없으면 자동으로 설치합니다. 맥 비밀번호를 물으면 입력하세요.
3. 대본 작성은 맥에 설치된 Claude Code(claude 명령)를 씁니다. 로그인만 되어 있으면 API 키는 필요 없습니다.
4. 처음 실행은 10~20분 걸릴 수 있습니다 (음성인식 모델 약 1.5GB 다운로드 포함).

[대행사 브랜드]
처음 실행할 때 대행사 로고(PNG)나 글자를 한 번 입력합니다. 영상 왼쪽 위와 마지막 엔딩 카드에 들어갑니다.
아무것도 입력하지 않으면 로고와 엔딩 카드 없이 만듭니다. 바꾸려면 메뉴 4번.

[작업 순서] - "실행_맥.command" 더블클릭 후 번호 선택
① 1번: 새 매장 폴더 만들기 → 매장 이름 입력
   → 작업/매장명_날짜/ 안에 1_촬영, 2_대본, 3_녹음, 4_완성 폴더가 생기고 1_촬영 폴더가 열립니다.
② 촬영 영상을 1_촬영 폴더에 넣기 (개수 제한 없음. 영상·사진 섞어도 됨). 파일 이름은 촬영 지침 컷번호로: 01_1.mp4, 05_2_best.mp4 ...
   01 훅클로즈업 02 들어올리기 03 조리 04 탑뷰 05 단면·칼질 06 진행자·인기 07 외관 08 메뉴판
③ 2번: 대본 만들기 → 매장 선택, 아는 정보(가격 등) 입력
   → 2_대본/script.md 가 열립니다. "확인 필요" 항목을 꼭 확인하세요. 대본은 고쳐도 됩니다.
④ 대본을 녹음해서 3_녹음 폴더에 넣기 (BGM을 쓰려면 이름에 bgm 이 들어간 파일도 함께)
⑤ 3번: 영상 완성하기 → 매장 선택
   → 4_완성 폴더에 reel.mp4(완성본), reel_cover.jpg(표지)

[자막 오타 고치기]
4_완성 폴더의 project.yaml 을 텍스트편집기로 열어 captions 의 text 를 고친 뒤,
터미널에서 (릴스메이커 폴더로 이동 후):  .venv/bin/python make_reel.py 작업/매장명_날짜/4_완성/project.yaml

[참고]
- 대본 작성은 Claude Code 사용량에 포함됩니다.
- 매장 이름·위치는 레퍼런스처럼 나레이션에 넣지 않습니다.
- 50초 영상 렌더링: M1 이상 맥 기준 약 3~5분
- 오류가 나면 터미널 창을 캡처해서 보내주세요.
