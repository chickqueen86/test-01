# 통합요약 v2: 진흙오리 릴스 (2차 분석 + 검수 반영)

근거 보고서: 01 촬영감독 · 02 편집감독 · 03 카피 · 04 사운드 · 05 마케터 · 06 검수.
v1에서 틀린 것은 맨 아래에 정리했습니다.

## 분석 범위
- 녹화본 0~3.28초는 녹화 중 릴스가 처음부터 다시 재생되기 전 구간이라 분석에서 뺐습니다. 3.28초에 표지가 깜빡이고 재시작됩니다. (06 발견, 메인 확인: 0~3.15초 화면이 3.6초 뒤 화면과 같음)
- **실제 영상은 3.33~49.15초, 약 45.8초입니다.** 아래 타임코드는 모두 녹화본 기준입니다.

## 확정 사항
| 항목 | 내용 | 근거 |

| 셋업·테이크 | 셋업 22개, 테이크 약 26개(25~27). 재사용은 7회(8→29, 9→18, 10→20, 11→21, 14→31, 16→27, 15→26) | 01 v2.1 |
| 훅 | 3.33~7.60초. 테이크 7개를 한 번씩, 분당 약 98컷. 반복은 없음 | 01, 06 |
| 템포 | 훅 98 → 가격 공개 38 → 식감 59 → ASMR 35 → 다른 메뉴 36 (분당 컷 수) | 02 + 06 재계산 |

| 자막 | 나레이션을 따라가며, 컷을 넘어가거나 컷 중간에 바뀝니다. 4~6자, 얇은 명조 계열 흰 글씨, 화면 중앙. 마침표·이모지·강조색 없음. "…?"는 예고할 때만 | 03, 06 |
| 나레이션 | 전체 약 7음절/초, 구간별 차이는 작습니다(가격 6.8, ASMR 7.5). 섹션 끝에서만 "-ㅂ니다"로 맺습니다 | 03 + 06 재계산 |
| 정보 순서 | 훅 → 메뉴명(7.6초) → "그런데.. 가격이...?" → 19,900원 + 진행자 등장(9.75초) → 보양식 통념 → 식감 → 소리 → 먹는 법(이 집의 킥) → 술 → 다른 메뉴 → "저장하시고 꼭 가보세요"(나레이션만) → 로고 | 03, 05 |
| 촬영 | 대부분 60p, 술 따르기 컷만 30p. 노란 도마 칼질은 삼각대 고정, 핸드헬드는 6컷. 매크로 극접사와 측역광 하드 키 | 01 v2.1 |
| BGM | 있음(Demucs로 분리). 드럼이 거의 없는 로파이·칠 패드, G# 단조 부근. 나레이션보다 16~24dB 아래에 깔리고 덕킹 없음. 베이스는 약 39초부터 | 04 v2 |
| 현장음 | 튀김·칼질 소리는 클립 원본 오디오입니다. 고역 경계 11곳 중 8곳이 컷 ±0.15초 안에 있습니다 | 04 v2 |
| 노출 | 상호와 위치는 영상·자막·나레이션 어디에도 0회. 가격은 화면에 2회(19,900원 / 2만원이 안되는), 캡션에 "치킨값" 1회 | 05 v2 |

- 폰트 이름, 원본 색값
- 23.4초 자막 일부(UI에 가려짐)
- 35~38.5초 하강 스윕 3회의 정체
