# 식당 릴스 메이커

촬영 소스(영상/사진) + YAML 문구 → 인스타 릴스(1080x1920, 30fps) 자동 생성.
스타일: 풀스크린 음식 클로즈업 · 좌상단 브랜드 로고 · 하단 중앙 외곽선 자막 · 강조 단어 컬러 · BGM 페이드아웃.

## 설치
- ffmpeg, Python 3.9+
- `pip install pyyaml pillow`
- 굵은 한글 폰트(Pretendard ExtraBold, 나눔스퀘어 EB 등)를 `style.font`에 지정 권장

## 사용
```bash
cd example
python ../make_reel.py project.yaml          # 1개
python make_reel.py 식당A/project.yaml 식당B/project.yaml   # 여러 개 일괄
```

## 장면 옵션
| 키 | 설명 |
|---|---|
| file | 영상 또는 사진 경로 |
| duration | 초 (사진 기본 3초, 영상 기본 최대 4초) |
| start | 영상 시작 지점(초) |
| speed | 영상 배속 (예: 1.5) |
| zoom | 사진 줌인 배율 (기본 1.15) |
| caption / captions | 자막 1개 / 여러 개(장면 시간을 균등 분할) |

자막에서 `\n`으로 줄바꿈, `style.highlight_words`에 있는 단어는 강조색으로 표시됩니다.

## 영상 + 나레이션 → 자동 완성 편집 (`auto_edit.py`)

```bash
pip install faster-whisper
python auto_edit.py 20261103_한우덮밥집/media 나레이션.m4a --music bgm.mp3 [--style 브랜드템플릿.yaml]
```

1. 나레이션을 음성인식해서 14자 안팎의 짧은 자막으로 자름 (단어 단위 싱크)
2. 자막이 바뀔 때마다 컷 전환. 촬영 지침의 파일명(`01_2_best.mp4`)을 읽어 컷 번호 순으로, `_best` 테이크를 우선 사용
3. 영상 길이 = 나레이션 길이. BGM은 나레이션 밑으로 자동으로 낮춤(15%)
4. 결과: `reel.mp4`, `project.yaml`(컷·자막 수정용), `captions.srt`

음성인식 오타(예: 출구 → 줄고)가 있으면 `project.yaml`의 captions만 고치고 `python make_reel.py .../project.yaml`로 다시 렌더링하세요.
정확도가 더 필요하면 `--model medium`을 쓰세요 (느려짐).
나레이션 파일 대신 나레이션이 녹음된 영상 파일을 넣어도 됩니다.

## v2: 레퍼런스 분석 적용 (team/00_통합요약.md 기준)
| 항목 | 적용 내용 |
|---|---|
| 색감 | 레퍼런스 80프레임 측정값(`presets/josun_color.json`)으로 클립별 색 매칭 (`color.strength`, 기본 0.85) |
| 컷 템포 | 구간별 컷 길이: 훅 0.61s → 가격 1.58s(진행자 2.6s 롱컷) → 식감 1.02s → ASMR 1.71s → 다른 메뉴 1.67s |
| 컷 순서 | 촬영지침 컷번호로 구간별 소스 풀 구성, 같은 테이크 연속 사용 금지 |
| 자막 | 나눔명조, 그림자, 화면 45% 지점, 컷과 독립된 나레이션 타임라인, 마침표 제거 |
| 소리 | 클립 현장음 유지(-10dB), BGM 나레이션 대비 -20dB(덕킹 없음), 압축 후 -17.5 LUFS |
| 엔딩 | 검은 화면 + 반짝이 + 로고 + present 1.3초, 자막 없음 |
| 표지 | `--cover "줄1|줄2|줄3"` → 노랑/흰 굵은 고딕 3줄 `reel_cover.jpg` |

녹화본 한계로 미적용: 슬로모션 배율, 정확한 폰트·BGM 템포, 칼날 와이프(촬영으로 만들어야 함).

## 색보정·필터 (v2.1)
- **색보정:** 클립마다 R/G/B 채널의 밝기 분포(1~99 백분위)를 레퍼런스 분포에 맞추는 톤 커브를 적용합니다. 레퍼런스 측정값은 진한 검정(파랑 하위 5%가 0), 강한 빨강, 화면의 84%가 붉은색·주황 계열입니다.
- **필터:** 선명도(unsharp 0.45), 하이라이트 번짐(glow 0.18, 기름 광택과 보케 느낌), 필름 입자(5)를 적용합니다. 레퍼런스는 가장자리가 중앙보다 밝아서(1.04) 비네트는 쓰지 않습니다.
- **검증:** 레퍼런스 컷 7개를 일부러 흐리게(대비·채도 낮춤) 만든 뒤 다시 보정했습니다. 원본과의 평균 오차가 49.5에서 13.5로 줄었습니다(0~255 기준). 비교 이미지는 `grade_test_compare.jpg`이고, 왼쪽부터 흐리게 만든 것 / 보정 결과 / 원본입니다.
- 조절은 project.yaml이나 프리셋에서 합니다: `color: {strength, saturation}`, `look: {sharpen, glow, grain, vignette}`

## 움직임 (v2.2)
- **최고 구간 선택:** 클립을 초당 6장으로 분석해 움직임(60%)과 선명도(40%) 점수가 가장 높은 구간만 잘라 씁니다. 같은 클립에서 이미 쓴 구간은 피합니다.
- **카메라 무빙 생성:** 잘라낸 구간의 움직임 값이 5.0 미만이면, 가감속이 들어간 푸시인(최대 110%)에 미세한 좌/우/상/하 슬라이드를 더합니다. 방향은 컷마다 바뀌고, 떨림을 막기 위해 2배 해상도에서 계산합니다.
- 컷별 강제 지정은 `move: true/false`, 전체 설정은 `motion: {auto, threshold, zoom}`입니다.

## 대본 작성 (v2.3, `write_script.py`)
촬영 폴더와 매장 이름을 넣으면 레퍼런스 공식대로 녹음용 대본(`script.md`)과 표지 문구(`script.json`)를 만듭니다.
- 기본은 맥의 Claude Code(`claude -p`, API 키 불필요), `--api`를 주면 Anthropic API(claude-opus-5-5)를 씁니다. 클립 대표 프레임으로 메뉴와 장면을 인식하고, 웹 검색으로 메뉴·가격을 확인합니다.
- 확인하지 못한 사실은 대본에 쓰지 않고 "확인 필요"에 따로 적습니다.
- 레퍼런스와 같이 매장 이름과 위치는 나레이션에 넣지 않습니다.
- 거절 대비 서버 측 fallback(`fallbacks: "default"`)을 켜 두었습니다.
- `auto_edit.py`는 촬영 폴더에 `script.json`이 있으면 그 표지 문구를 자동으로 씁니다.

## 음악·효과음 (v2.4, `audio_gen.py`)
- **배경음악:** 음악 파일을 따로 주지 않으면 레퍼런스 스타일로 자동 작곡합니다. 드럼이 거의 없는 로파이 패드, G# 단조, 115 BPM이고, 베이스는 전체 길이의 82% 지점부터 들어오며 바이닐 잡음을 깝니다. 나레이션보다 20dB 낮게 섞습니다.
- **효과음:** 원본에 소리가 없는 음식 컷(굽기, 조리, 탑뷰, 단면)에 굽는 소리(지글지글)를 넣고, ASMR 구간에는 써는 소리(바삭)를 넣습니다. 레퍼런스처럼 컷 시작 0.05~0.15초 뒤에 들어가고, 전환 효과음은 넣지 않습니다(하드컷).
- **현장음:** 원본에 현장음이 있는 클립은 합성음 대신 현장음을 그대로 씁니다.
- **설정:** `bgm: {generate, bpm}`, `sfx: {enabled, db}`

## 나레이션·자막·장면 매칭 (v2.5)
- **나레이션 속도 자동 조절:** 앞뒤 무음을 자르고, 문장 사이 0.15초 넘는 쉼은 0.1초로 줄인 뒤, 음높이를 유지한 채 초당 7음절(레퍼런스)에 가깝게 빠르게 합니다(최대 1.3배). 끄려면 `--no-pace`.
- **자막:** 글자는 대본(script.json) 그대로 쓰고, 시간만 목소리 인식 결과에서 가져옵니다. 받아쓰기 오타가 생기지 않습니다.
- **장면 매칭:** 대본의 `section_shots`(구간별로 내용이 맞는 촬영 파일)를 우선 사용합니다. 대본 단계에서 자동으로 작성됩니다.
- **엔딩 카드:** 대행사 브랜드가 없으면 엔딩 카드 없이 나레이션 길이에 딱 맞춥니다.
