# 나레이션 대본 템플릿 (레퍼런스: 진흙오리 릴스, 50초)

한 줄 = 자막 1개 = 1~2초. 짧게 끊어 읽기. 빠른 톤.

| 구간 | 시간 | 예시 (레퍼런스) |
|---|---|---|
| 훅 | 0~8초 | 스킵하면 / 다시는 못 볼 / 귀르가즘 끝판왕 / 신기한 비주얼을 지닌 / 한정판 진흙오리전병입니다 |
| 가격 | 8~16초 | 그런데 가격이 / 단돈 19,900원에 / … 착한 가격에 팔고 있습니다 |
| 맛·소리 | 16~32초 | 바삭바삭 겉바속촉 / 특제 겨자소스를 바르고 / 칼을 살짝 대기만 해도 / 썰리는 소리가 벌써 맛있어요 |
| 곁들임·술 | 32~38초 | 만두피, 양상추와 함께 / 하이볼은 병으로도 잔으로도 팝니다 |
| 다른 메뉴 | 38~46초 | 얼큰해장 닭전골도 / 단짠단짠 / 치즈불닭은 실패 없는 조합 |
| 마무리 | 46~50초 | 저장하시고 꼭 가보세요 / 스킵하면 ← 첫 문장으로 되돌아가 무한 반복 |

- 끝 문장을 첫 문장("스킵하면")으로 이어 붙여서 릴스가 자연스럽게 반복 재생되게 함
- 가격, 의성어(바삭바삭), 감탄 표현을 꼭 넣기
